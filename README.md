# 🚀 Master en Programación y Desarrollo Web

¡Bienvenido/a a mi repositorio de la **Master Class de Programación y Desarrollo Web**! 🎓

## 📌 Descripción del Proyecto

Este repositorio se encuentra estructurado en **módulos independientes organizados en carpetas**. A medida que avanzo en el curso, voy subiendo los ejercicios, proyectos y prácticas correspondientes a cada tecnología.

A lo largo de este master iré completando prácticas y proyectos en las siguientes tecnologías:

- ⚡ **JavaScript (ES6+)** (Lógica avanzada, manipulación del DOM, Asincronía)
- 📄 **JSON** (Estructura y gestión de datos)
- 🟢 **Node.js** (Desarrollo Backend y APIs RESTful)
- 🟦 **TypeScript** (JavaScript con tipado estático)
- 🅰️ **Angular** (Desarrollo de aplicaciones SPA avanzadas)
- 🍃 **Stack MEAN** (MongoDB, Express, Angular, Node.js)
- 🚀 **Astro** (Framework moderno orientado al rendimiento)

## 🚀 Cómo Explorar el Repositorio

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/jhonmario7/master-desarrollo-web-JS.git
   ```
2. **Acceder a un módulo específico:**
   ```bash
   cd aprendiendo-css
   ```
3. **Ejecutar o visualizar:**
   - Para proyectos frontend (HTML/CSS/JS), puedes abrir el archivo `index.html` en el navegador o usar **Live Server** en VS Code.
   - Para proyectos de Node/Angular/Astro, consulta el `README.md` específico dentro de su respectiva carpeta.
